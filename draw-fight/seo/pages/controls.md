# ラクガキファイターの操作方法｜PC・スマホ完全ガイド

ラクガキファイターの操作方法は、PCではキーボードとマウス、スマホではタッチ操作が基本です。どちらも同じバトルルールなので、使いやすい端末から遊べます。まずは移動・攻撃・防御の三つを覚えましょう。

## PCのバトル操作

### 移動・攻撃・防御

| 動作 | キー | ポイント |
|---|---|---|
| 移動 | W / A / S / D または矢印キー | 相手との距離を調整 |
| 通常攻撃 | J または Space を短く押して離す | 連打よりタイミングを意識 |
| 重い攻撃 | J または Space を長押しして離す | 耐力を多く使う |
| 防御 | K または Shift を押し続ける | 攻撃が来るタイミングを狙う |
| 一時停止・再開 | Esc | 戦闘中に利用 |

攻撃は「押す」だけでなく「離す」ときの動きが重要です。押しっぱなしでも無限に攻撃し続けるわけではありません。基本操作を練習するなら、最初のステージで通常攻撃と重い攻撃を交互に試してみてください。

## PCのお絵描きショートカット

### ペンとやり直し

| 動作 | キー |
|---|---|
| ペン | B |
| ぬりつぶし | G |
| 消しゴム | E |
| もどす | Ctrl + Z / Command + Z |
| やりなおす | Ctrl + Shift + Z / Command + Shift + Z |

ペンの色や太さは画面のツールで変更できます。キーボード操作が得意でなくても、マウスだけで絵を描くことができます。

## スマホのバトル操作

### スティックとボタン

スマホでは左側のバーチャルスティックで移動し、右側の攻撃・防御ボタンを使います。通常攻撃は短く押して離し、重い攻撃は長押しから離して出します。防御は押している間だけ有効です。基本操作は画面内の案内でも確認できます。

## よくある操作トラブル

### 動かない・攻撃できない

**キャラが動かない：** 戦闘中か確認し、PCなら文字入力欄にフォーカスが残っていないか見てください。**攻撃できない：** 耐力不足や行動中の可能性があります。**長押し攻撃にならない：** 十分に長押ししてから離してください。**スマホでボタンが押しにくい：** 端末を持ち直し、ページを拡大せずゲーム領域を使ってみてください。
